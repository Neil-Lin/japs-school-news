# 學校基本資料與校園開放資訊

五校頁面與根頁在「最近檢查」下方提供 info 圖示及「基本資訊」文字入口。桌機燈箱與手機全螢幕層沿用午餐的視覺樣式，關閉、Escape、返回會保留公告搜尋、分類、頁碼及位置；返回後可前進重開。入口採文字外觀，具按鈕語意與至少 44px 高的觸控範圍。

聯絡資訊使用固定標籤欄與對齊的內容欄，電話、官網保留44px觸控高度；地址的導航在桌機置於同列右側，手機放於地址下方。資料來源集中在底部可展開區，各項查核日期放在展開內容，逾期時收合摘要也會提醒；鍵盤焦點包含該區摘要，並排除收合區內的隱藏連結。

## 資料與來源

`school-info.json` 是人工核對的獨立快照，查核日期不沿用公告 RSS 的檢查時間。基本資料來自教育部 115 學年度國小名錄，並逐校核對官方首頁電話與地址。博愛的名錄地址含里鄰文字，顯示值依官網整理為松仁路95巷20號。

- 名錄：https://data.gov.tw/dataset/6087
- 名錄 CSV：https://stats.moe.gov.tw/files/school/115/e1_new.csv
- 校園開放資料：https://data.taipei/dataset/detail?id=82c0badd-efbe-4e96-8153-885494c72cd1

時段不能用市級法規預設值補齊，也不推算「現在開放」。資料差異採以下方式呈現：

- 仁愛：依校方「門禁事項／運動場開放時間」文件列出一般平日18:30–21:30，保留寒暑假17:00–21:30的差別。市府登錄平日晚間17:50與校方文件不同，已標註。
- 建安：依校方114學年度第2學期學校日宣導資料列出夜間19:00–21:00、週末09:00–17:00。市府另列早晨及較長週末時段，未合併推論；顯示來源學期與需洽校確認的說明。
- 敦化：市府登錄「因施工未開放」且無恢復日期，保留登錄說明並引導洽校確認。不把羽球場租借規定當成全校開放狀態。
- 博愛：依市府登錄的一般時段呈現。
- 光復：依市府登錄呈現；較早校方管理原則的平日時段不同，已提醒出發前洽校確認。

每校保留採用來源、原始名錄與市府資料列。所有內容在建置時驗證並轉成有跳脫的 HTML，因此離線及公告讀取失敗時仍能查看。原始快照與維護工具不進公開套件；各頁只嵌入該校資料。

## 近期場地公告

從完整的本校公告（不受目前分類或搜尋影響）挑出近90天內、標題涉及校園／操場／球場／遊戲場及開放／封閉／施工的校方原文，依發布時間列出最多3筆。顯示「請點原文確認適用日期與範圍」，不推論公告是否仍生效，也不將找不到公告解讀為已開放。這是相關公告輔助入口，不承諾涵蓋所有臨時異動。

## 維護

每月至少核對一次，並於新學年度更換名錄來源：

```sh
python3 scripts/check_school_info_sources.py
```

此工具只讀取兩個公開 CSV，逐校比較代碼／完整校名與資料列。來源變更、缺漏或重複比對即失敗；不自動覆寫人工核對結果，也不更新查核日期。若失敗，須檢查各校官網與開放公告後再修改快照，保留來源差異。即使 CSV 未變更，也要人工核對校方文件與公告，才能更新該校的 `reviews.contact.checkedOn` 或 `reviews.opening.checkedOn`。每項目前30天查核一次，超過期限在資料來源區標記待重新查核；不影響公告與午餐的時間。詳細排程與報告見 [維護工程](maintenance.md)。

修改後執行 `python3 scripts/build_site.py`、`python3 scripts/check_project.py`、`python3 scripts/build_site.py --output dist`，循既有 PR 與 Pages 流程發布。基本資料變更會重新產生頁面及 shell；不改寫 RSS 或午餐資料。
